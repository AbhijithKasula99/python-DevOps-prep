# Python GenAI Engineer Preparation

A hands-on Python learning journey from fundamentals to production-ready Python, designed around the requirements of a Senior Generative AI Engineer role.

## Goal

Build strong Python fundamentals first, then progressively develop the engineering skills required to build production GenAI applications.

## Learning Approach

- Learn one concept at a time
- Write the code ourselves
- Run it in WSL
- Understand errors and debugging
- Document what we learn
- Commit progress regularly
- Build a reusable learning guide
